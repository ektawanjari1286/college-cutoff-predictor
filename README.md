# 🎓 College Cutoff Predictor

A machine learning-based web application designed to help students explore college admission possibilities based on cutoff-related information.

🚀 **Live Demo:** [College Cutoff Predictor](https://college-cutoff-predictor-n3k99cnlvbqft2nmcgwuqv.streamlit.app/)

## 📌 Project Overview

The **College Cutoff Predictor** is a web application built using Python and Streamlit. It aims to make college prediction easier by providing an interactive interface for students to explore admission possibilities.

Instead of manually searching through cutoff information, users can use the application to get insights that help them plan their college preferences.

## ✨ Features

* 🎓 College cutoff prediction interface
* 📊 Data-driven prediction approach
* 🖥️ Interactive web application
* ⚡ Easy-to-use interface
* 🌐 Accessible online through Streamlit
* 📱 Usable through a web browser on desktop and mobile

## 💻 Run the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/ektawanjari1286/college-cutoff-predictor.git
```

### 2. Navigate to the project directory

```bash
cd college-cutoff-predictor
```

### 3. Create a virtual environment (optional)

```bash
python -m venv venv
```

Activate it on Windows:

```bash
venv\Scripts\activate
```

### 4. Install dependencies

If a `requirements.txt` file is available:

```bash
pip install -r requirements.txt
```

Otherwise, install the required packages used by your project:

```bash
pip install streamlit pandas numpy scikit-learn
```

### 5. Run the Streamlit application

```bash
streamlit run app.py
```

The application will open in your browser, usually at:

`http://localhost:8501`
